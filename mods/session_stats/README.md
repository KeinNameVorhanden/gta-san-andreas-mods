# Session stats (SACore example)

SACore mod `session_stats`.

- Build: `cmake --build --preset x86-release --target session_stats`
- Deploy to a test copy: `python tools/deploy_dev.py --game <test copy> --mod session_stats --apply`
- Package: `python tools/package_mod.py session_stats`
- Settings: `sacore\config\mods\session_stats.toml` (declared in `mod.toml [config]`)
