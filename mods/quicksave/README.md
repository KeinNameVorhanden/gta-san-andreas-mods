# Quick save

SACore mod `quicksave`.

- Build: `cmake --build --preset x86-release --target quicksave`
- Deploy to a test copy: `python tools/deploy_dev.py --game <test copy> --mod quicksave --apply`
- Package: `python tools/package_mod.py quicksave`
- Settings: `sacore\config\mods\quicksave.toml` (declared in `mod.toml [config]`)
